Privacy Policy, HEATZY Uploader

Last updated: 18 October 2026

HEATZY Uploader is a personal tool run by the owner of the YouTube channel HEATZY YT. It uses Google's YouTube Data API only to upload videos the owner made to the owner's own channel and to set their title, description, tags and publish time.

What data is used

The tool asks Google for permission to upload videos to the signed-in YouTube account. The sign-in token is stored only on the owner's own computer. The tool does not collect, store, sell or share any data about viewers or any other person.

Google user data

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. Access can be removed at any time at myaccount.google.com/permissions.
